# واجهة إدارة المشروع (Project Management) - التوثيق النظري

## نظرة عامة

واجهة إدارة المشروع هي لوحة التحكم الخاصة بصاحب المشروع (Employer) للإشراف على مشروعه من لحظة نشره حتى اكتماله ودفع المستحقات. تتيح هذه الواجهة متابعة التقدم، تنظيم المراحل (Milestones)، إدارة فريق العمل، تشغيل نظام الدفع بضمان (Escrow)، والتحكم بإعدادات المشروع بدقة.

الواجهة تدعم العربية والإنجليزية واتجاه RTL، وهي مقسمة إلى:

- **رأس ثابت (Header)** يعرض ملخصاً سريعاً عن المشروع.
- **شريط تبويبات (Tabs)** يحتوي على خمسة أقسام رئيسية.
- **منطقة محتوى** تتغير حسب التبويب المختار مع تأثير انتقال سلس.

### رأس الواجهة (Header)

يظهر في أعلى الصفحة داخل بطاقة، ويحتوي على العناصر التالية:

| العنصر | الوصف |
|--------|-------|
| زر الرجوع | أيقونة سهم تعيد المستخدم إلى صفحة عرض المشروع `myProject/[id]`. |
| عنوان المشروع | اسم المشروع مع عرض فئته ونص "إدارة المشروع". |
| مؤشرات سريعة (Compact Stats) | أربعة ملصقات صغيرة: نسبة التقدم، مدة المشروع بالأيام، عدد المراحل، عدد أعضاء الفريق. |
| شارة الحالة (Status Chip) | تظهر حالة المشروع بألوان دلالية: مفتوح (أخضر)، قيد التنفيذ (أزرق)، مكتمل (رمادي)، ملغى (أحمر). |

### شريط التبويبات

خمسة تبويبات قابلة للتمرير (Scrollable)، كل تبويب يحمل أيقونة ونصاً:

1. **نظرة عامة (Overview)** — الأيقونة: ملخص `SummarizeOutlined`
2. **المراحل (Timeline/Milestones)** — الأيقونة: علم `FlagOutlined`
3. **الفريق (Team)** — الأيقونة: مجموعة `GroupOutlined`
4. **المدفوعات (Payments)** — الأيقونة: دفعات `PaymentsOutlined`
5. **الإعدادات (Settings)** — الأيقونة: ترس `SettingsOutlined`

> ملاحظة: عند فتح الواجهة عبر الرابط `?tab=payments` يتم توجيه المستخدم مباشرة إلى تبويب المدفوعات.

## التبويب الأول: نظرة عامة (Overview)

هذا التبويب هو لوحة القيادة البصرية التي تجمع أهم مؤشرات المشروع في لمحة واحدة، ويقسم محتواه إلى بطاقات (Cards) مرتبة كالتالي:

### 1. بطاقة التقدم الرئيسية (اليسرى)
- **حلقة التقدم (Progress Ring):** رسم دائري متحرك يعرض نسبة الإنجاز العامة للمشروع. يتغير لون الحلقة حسب النسبة: أخضر عند الاكتمال (100%)، بنفسجي عند 50% فأكثر، برتقالي أقل من ذلك.
- **الميزانية الإجمالية (Total Budget):** يظهر الحد الأدنى للميزانية مع العملة.
- **الفترة الزمنية للمشروع (Project Period):** تاريخ البداية وتاريخ النهاية.
- **الموعد النهائي (Deadline):** التاريخ النهائي للتسليم.

### 2. بطاقة ملخص المدفوعات (Payments Summary)
- **رسم دائري مجوف (Doughnut Chart):** يقسم المدفوعات إلى "مدفوع" (أخضر) و"معلّق/بانتظار" (برتقالي).
- ثلاثة صفوف توضيحية: الإجمالي، المدفوع، المعلّق — مع أيقونات نقدية وحالة مناسبة.

### 3. بطاقة التقدم الزمني (Timeline Progress)
- **شريط زمني متحرك:** يوضح كم مرّ من الزمن منذ بداية المشروع حتى اليوم بالنسبة لتاريخ النهاية، مع علامة (نقطة) متحركة على الخط.
- يعرض تاريخ البداية والنهاية ونسبة الزمن المنقضي، مع مدة المشروع بالأيام وحالته.
- في حال عدم تحديد تواريخ، تظهر رسالة تطلب تعيين تاريخ البداية والنهاية.

### 4. بطاقة توزيع المراحل (Milestones Breakdown)
- **رسم بياني شريطي (Bar Chart):** يصنّف المراحل إلى ثلاثة أعمدة: مكتملة (أخضر)، قيد التنفيذ (بنفسجي)، لم تبدأ بعد (رمادي).
- إذا لم توجد مراحل يظهر نص "لا توجد مراحل بعد".

### 5. معاينة الفريق (Team Preview)
- تعرض صفاً من أعضاء الفريق (الصورة، الاسم، الدور) إذا كان هناك أعضاء مضافون.

**الهدف من هذا التبويب:** إعطاء صاحب المشروع صورة شاملة وسريعة عن صحة المشروع دون الحاجة للدخول في التفاصيل.

## التبويب الثاني: المراحل (Milestones / Timeline)

المراحل هي تقسيم المشروع إلى خطوات أو أهداف فرعية، لكل مرحلة تاريخ بداية ونهاية وتقدّم مستقل. هذا التبويب يدير دورة حياة هذه المراحل.

### العرض
- تعرض المراحل في **خط زمني عمودي (Vertical Timeline)** بترتيب زمني، كل مرحلة كبطاقة تحمل:
  - **العنوان** مع **شارة الحالة** (لم تبدأ / قيد التنفيذ / مكتملة).
  - **الوصف** (إن وُجد) مع أيقونة ملاحظة.
  - **تاريخ البداية والنهاية** بجانب أيقونة تقويم.
  - **الشخص المسند إليه** (صورة مصغرة + الاسم) إن وُجد.
  - **شريط التقدم (Linear Progress):** يوضح نسبة إنجاز المرحلة بلون يطابق حالتها.
  - أزرار **تعديل** و**حذف** في الزاوية.
- نقاط ملوّنة على الخط الزمني تشير إلى حالة كل مرحلة.
- عند عدم وجود مراحل يظهر رسم توضيحي ونص "لا توجد مراحل بعد".

### إضافة / تعديل مرحلة (النافذة المنبثقة - Dialog)
عند الضغط على "إضافة مرحلة" أو أيقونة التعديل، تفتح نافذة تحتوي على الحقول التالية:

| الحقل | الوصف |
|-------|-------|
| العنوان (Title) | اسم المرحلة — حقل مطلوب. |
| الوصف (Description) | تفاصيل اختيارية عن المرحلة. |
| تاريخ البداية (Start Date) | منتقي تاريخ. |
| تاريخ النهاية (End Date) | منتقي تاريخ. |
| المسند إليه (Assigned To) | قائمة منسدلة بأعضاء الفريق لاختيار المسؤول عن المرحلة. |
| الحالة (Status) | قائمة منسدلة: لم تبدأ / قيد التنفيذ / مكتملة. |
| التقدم (Progress) | منزلق (Slider) من 0 إلى 100%. |

تظهر رسالة خطأ إن تُرك العنوان فارغاً، وعند الحفظ تُحدَّث بيانات المشروع ويُعاد تحميل النظرة العامة.

## التبويب الثالث: الفريق (Team)

يدير هذا التبويب الأعضاء (المستقلين/الموظفين) المرتبطين بالمشروع، سواء عبر قبول عرض (Proposal) أو بالإضافة اليدوية.

### العرض
- شبكة بطاقات (Grid) لكل عضو، تعرض:
  - **الصورة الرمزية** والاسم الكامل.
  - **العنوان الوظيفي / البريد** أسفل الاسم.
  - **شارة الدور (Role Chip):** الدور المعيَّن مثل "مطوّر خلفي".
  - **شارة الحالة (Status Chip):** مدعو (أزرق)، يعمل (أخضر)، مكتمل (بنفسجي)، مُزال (أحمر).
  - **تاريخ الانضمام (Joined):** متى انضم العضو للمشروع.
  - مؤشر **"تم التوظيف عبر عرض"** (أيقونة تحقق) إن كان العضو جاء من مقترح مقبول.
  - أزرار **تعديل** و**إزالة**.
- عند عدم وجود أعضاء يظهر رسم ونص "لا يوجد أعضاء فريق بعد".

### إضافة / تعديل عضو (النافذة المنبثقة)
| الحقل | الوصف |
|-------|-------|
| معرّف المستخدم المستقل (Freelancer User ID) | يظهر فقط عند الإضافة — يُلصق معرّف المستخدم المراد إضافته. |
| الدور (Role) | نص حر يصف مهمة العضو، مطلوب عند التعديل. |
| الحالة (Status) | مدعو / يعمل / مكتمل / مُزال. |

عند الإزالة يُطلب تأكيد عبر نافذة المتصفح.

## التبويب الرابع: المدفوعات (Payments)

هو القسم المالي للواجهة، ويُشغّل نظام **الدفع بضمان (Escrow)** الذي يحمي الطرفين: يُحتجز المبلغ حتى إنجاز العمل ثم يُحرَّر للمستحق.

### المؤشرات العلوية (Stat Cards)
ثلاث بطاقات ملخّصة:
- **الإجمالي (Total):** مجموع كل المدفوعات.
- **المحتجز (Held):** المبالغ المودعة ولم تُحرَّر بعد (برتقالي).
- **المُحرَّر (Released):** المبالغ التي وُزّعت على المستحقين (أخضر).

### قائمة الفواتير / المدفوعات
كل عملية دفع تظهر كبطاقة تحتوي على:
- أيقونة وحالة الضمان: **محتجز (held)**، **مُحرَّر (released)**، **مُسترد (refunded)**، **ملغى (cancelled)**.
- **المبلغ** بعملة المشروع.
- **تاريخ الإنشاء**، **طريقة الدفع** (بطاقة/محفظة)، **رقم المرجع (Reference)**.
- **المستحِق (Payee):** اسم العضو الذي سيستلم المبلغ.
- زر **تحرير (Release)** يظهر فقط للمدفوعات "المحتجزة" لإطلاقها إلى محفظة المستحق.

### نافذة إجراء دفعة جديدة (Make a Payment)
تُفتح عند الضغط على "إضافة دفعة" وتتضمن:

1. **تنبيه بيئي تجريبي:** ملاحظة أن البيئة تجريبية ولا يُعالج دفع حقيقي.
2. **المستحِق (Payable to):** قائمة أعضاء الفريق النشطين للاختيار، مع تمييز "مقترح مقبول" مقابل "عضو فريق". يُحتجز المبلغ في الضمان حتى الاكتمال.
3. **المبلغ (Amount):** حقل رقمي.
4. **طريقة الدفع (Payment Method):** ست بطاقات قابلة للاختيار:
   - بطاقات: Visa، Mastercard، American Express — تظهر **معاينة بطاقة (Card Preview)** متحركة مع حقول الرقم والانتهاء وCVV.
   - محافظ: PayPal، Apple Pay — تظهر ملاحظة التوجيه/التأكيد.
   - **ShamCash:** حقول رمز المستقبل، الرمز الشخصي، ورفع صورة إيصال الدفع.
5. **ملاحظة (Note):** نص حر اختياري.
6. شريط سفلي يوضح حماية SSL وزر **"ادفع"** يعرض المبلغ المُدخل.

### نافذة تأكيد التحرير (Release Payment)
عند تحرير دفعة محتجزة، تظهر نافذة تأكيد تعرض مبلغ الدفعة وتنبّه بأن **رسوم المنصة ستُخصم** عند التحرير، مع زر "تحرير".

## التبويب الخامس: الإعدادات (Management Settings)

يضبط هذا التبويب المعلمات العامة للمشروع: التواريخ، الحالة، التقدم، وإعدادات الدفع. مقسّم إلى ثلاث بطاقات:

### 1. الجدول والتواريخ (Schedule & Dates)
- **تاريخ النشر (Published Date):** متى نُشر المشروع.
- **تاريخ البداية / النهاية (Start / End Date):** منتقيان للفترة الزمنية.
- **الحالة (Status):** قائمة منسدلة: مفتوح، قيد التنفيذ، مكتمل، ملغى.

### 2. التقدم (Progress)
- **منزلق التقدم (Slider):** لتحديد نسبة الإنجاز يدوياً (0–100%) مع شارة تعرض القيمة.
- ملاحظة توضيحية: عند وجود مراحل، يُحسب التقدم تلقائياً كمتوسط تقدّم المراحل.

### 3. إعدادات الدفع (Payments Configuration)
- **الدفع على مرحلتين (Two-stage payment):** مفتاح (Switch) لتفعيل الدفع على خطوتين.
- **عدد الأقساط (Installments Count):** حقل رقمي.
- **المبلغ الإجمالي (Total Amount):** حقل رقمي لتحديد ميزانية الدفع الكلية.

بعد التعديل يظهر زر **"حفظ الإعدادات"**، وعند الضغط عليه تُفتح نافذة **تأكيد الحفظ** تعرض ملخصاً (الفترة، الحالة، التقدم) قبل الإرسال الفعلي.

## سلوك الواجهة العام

- **التحميل:** تُجلب بيانات المشروع مرة واحدة عند الدخول عبر `getProjectOverview`، ويظهر مؤشر دائري دوّار أثناء التحميل.
- **معالجة الأخطاء:** إن فشل جلب البيانات تظهر رسالة خطأ مع زر "إعادة المحاولة" وزر "العودة للمشروع".
- **الإشعارات (Toast):** بعد أي تعديل ناجح (مرحلة/فريق/دفعة/إعدادات) يظهر إشعار علوي يؤكد نجاح العملية وتُحدَّث البيانات في الخلفية دون إعادة تحميل كاملة.
- **التصميم المتجاوب:** جميع التبويبات تتكيف مع الجوال والحاسوب، والنوافذ المنبثقة تتحول لملء الشاشة على الشاشات الصغيرة.
- **الحركة (Animations):** انتقال سلس بين التبويبات، وظهور تدريجي للبطاقات والأرقام المتحركة لإحساس عصري.

## ملخص سريع للتبويبات

| التبويب | الغرض الأساسي | أبرز العمليات |
|---------|---------------|----------------|
| نظرة عامة | لوحة قيادة بصرية شاملة | عرض التقدم، المدفوعات، الزمن، المراحل، الفريق |
| المراحل | تنظيم خطوات المشروع | إضافة/تعديل/حذف مرحلة، إسناد عضو، تتبع تقدمها |
| الفريق | إدارة الأعضاء | إضافة/تعديل/إزالة عضو، تحديد الدور والحالة |
| المدفوعات | نظام الضمان المالي | إيداع دفعة، اختيار المستحق والطريقة، تحرير المبلغ |
| الإعدادات | ضبط معلمات المشروع | تعديل التواريخ، الحالة، التقدم، إعدادات الدفع |
